Accueil Maxime - launcher Android TV

1. Ouvrir le dossier atv-launcher dans Android Studio (Open).
2. Attendre la synchronisation Gradle.
3. Activer le mode développeur sur la TV : Paramètres > Préférences relatives à l'appareil > Informations > appuyer 7 fois sur "Version" / "Build".
4. Options pour les développeurs > activer "Débogage ADB" et "Débogage réseau" (ou équivalent).
5. Noter l'adresse IP de la TV : Paramètres > Réseau et Internet.
6. Sur le PC : adb connect ADRESSE_IP_TV:5555
7. Dans Android Studio, choisir la TV dans la liste des appareils et cliquer sur Run.
8. Sur la TV, appuyer sur le bouton Accueil et choisir "Accueil Maxime", puis "Toujours".
